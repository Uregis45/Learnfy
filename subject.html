📘 Complete HTML Tags Reference

Each tag includes a description — just like w3schools. This page uses <dl> (description list) to explain each element.

📝 Basic & Formatting Tags

<h1> – <h6>
Headings, with <h1> being the most important.
<p>
Paragraph of text.
<strong>
Important text (bold).
<em>
Emphasized text (italic).
<mark>
Highlighted text.
<small>
Smaller text.
<del>
Deleted text.
<ins>
Inserted text.

📋 List Tags (including Description List)

<ul>
Unordered list (bullets).
<ol>
Ordered list (numbers).
<li>
List item.
<dl>
Description list – the perfect tag for definitions.
<dt>
Term in a description list.
<dd>
Description of the term.

🔗 Links & Media

<a>
Anchor (hyperlink).
<img>
Image.
<figure>
Self-contained content (image + caption).
<figcaption>
Caption for <figure>.
<video>
Video player.
<audio>
Audio player.

📊 Table Tags

<table>
Table container.
<tr>
Table row.
<th>
Table header cell.
<td>
Table data cell.
<caption>
Table caption.

📮 Form Tags

<form>
Form container.
<input>
Input field (text, password, etc.).
<textarea>
Multi-line text input.
<select>
Dropdown list.
<button>
Clickable button.
<label>
Label for form elements.
<fieldset>
Group related form elements.
<legend>
Caption for <fieldset>.
